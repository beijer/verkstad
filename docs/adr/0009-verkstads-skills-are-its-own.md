# verkstad's skills are its own

This supersedes ADR 0002. Every skill verkstad uses is its own: `verkstad:grill`, `verkstad:spec`, `verkstad:tickets`, `verkstad:triage` and `verkstad:review` are written here, and the tdd and diagnose skills the loop once borrowed are gone, because Opus 5.5 no longer needs them. A skill, agent or prompt still calls another skill by its verkstad name. The rules that keep an implementer's change small (Ponytail's) live in the implementer's system prompt, `agents/implementer.md`, so every implementer session carries them without another plugin, and `NOTICE.md` credits what was copied. The formats a Project is written in change only through an ADR here, as ADR 0003 says. With nothing borrowed, the Gate's `borrowed` check and its script are deleted. We rejected keeping Borrowed skills, because each one tied a Run to another plugin's wording and release, and to its being installed. The evidence is in [docs/research/2026-10-12-own-skills.md](../research/2026-10-12-own-skills.md).
