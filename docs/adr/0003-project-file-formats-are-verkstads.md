# The Project file formats are verkstad's own

The formats Projects are written in came from mattpocock-skills: `CONTEXT.md` as a glossary with `_Avoid_` lines, ADRs in `docs/adr/`, `docs/agents/*`, the Ticket template (Parent, What to build, Acceptance criteria, Blocked by) and the Agent Brief. verkstad documents them as its own formats, in this repo, rather than relying on that plugin to define them. Moving away from a Borrowed skill then never touches a Project's files: Ray alone has 177 issues, a `CONTEXT.md` and seven ADRs in these formats. A format changes only through a new ADR here.
